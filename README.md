Un semplice script che calcola i valori di un prisma rettangolare.

Inserisci le lunghezze di lato1, lato2, altezza e ritorna:

- Perimetro della base
- Area della base
- Area laterale
- Area totale
- Volume
- Diagonale

Questo è il primo programma che ho scritto nella mia vita, apprezzo qualsiasi feedback.
